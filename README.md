# Agentic Software Development

A Claude Code plugin that gives an AI agent — and the person directing it — a
**method** for building real software: plan before code, stop at the right
moments, prove it works, ship through a pull request.

Built for people who can describe what they want but have never opened a
terminal, and for developers who are tired of agents that produce a thousand
lines nobody asked for.
