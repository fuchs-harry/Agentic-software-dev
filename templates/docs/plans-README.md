# Plans

Every unit of work gets a node here before any code is written. Copy to
`docs/plans/README.md`.

```
docs/plans/<slug>/
├── README.md     the plan   — for the person who approves it
└── brief.md      the brief  — for whoever builds it
```

A plan that is not listed below is a plan nobody approved.

---

**Status values:** `draft` · `awaiting approval` · `approved` · `in progress` ·
`shipped (#42)` · `abandoned`

**When a plan is not needed:** pure investigation with no edit, a typo or a
one-liner, a change entirely inside `docs/`. Everything else gets a node —
when in doubt, write one. A plan that turned out too small costs ten minutes;
a missing one costs a branch.
